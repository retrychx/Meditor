AI Agent

Your AI writes, refactors, and edits — with real tool calls.

MEditor ships with a full AI Agent, not just a chat panel. It reads your document, calls tools to patch specific sections, searches your workspace — and shows every step transparently.

  • Multi-turn reasoning loop that runs to completion
  • Document tools: read, write, patch, insert with precision
  • OpenAI & Anthropic SSE streaming, both wire protocols
  • Skill system — built-in + an extensible gallery
🤖

Editor

A real editor. Not an afterthought.

Syntax highlighting for 40+ languages, bidirectional scroll sync with anti-loop protection, native find & replace with jump-to-line, and a fuzzy file finder (⌘P) — everything you'd expect from a desktop app.

  • Live Markdown preview with Mermaid diagram support
  • Drag-to-reorder tabs, close confirmation, reopen closed tab
  • GitHub Light, Nord, and Dracula themes
  • Session restore across launches — tabs, folder, selection
